# MultiDialect-ASR Demo

Dialect recognition examples with **inline audio players** and model transcriptions.

Dialects: **Cantonese** · **Minnan** · **Sichuan** · **Wu** (5 samples each).

## Interactive page (recommended)

Open the playable page here (no GitHub Pages needed):

**[Open Interactive Demo](https://htmlpreview.github.io/?https://github.com/ASLP-lab/MultiDialect-ASR/blob/main/demo/index.html)**

Local preview:

```bash
python3 -m http.server 8766 --directory .
```

Then open `http://127.0.0.1:8766/`.
